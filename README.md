# 🎮 Tic Tac Toe Game (C# Windows Forms)

A clean and interactive implementation of the classic **Tic Tac Toe (X-O)** game built using **C# Windows Forms**.  
This project demonstrates core programming concepts, OOP principles, and event-driven UI development.

---

## 🚀 Overview

This application allows two players to compete on a 3x3 grid.  
The game automatically detects:

- Winning conditions (rows, columns, diagonals)
- Draw situations
- Player turns and game flow

The project was built as part of my learning journey in software development to strengthen my understanding of **C# and desktop application development**.

---

## ✨ Key Features

- 👥 Two-player local gameplay (X and O)
- 🧠 Automatic win detection (row, column, diagonal)
- 🤝 Draw detection
- 🖱️ Interactive Windows Forms UI
- 🔄 Game reset / replay functionality
- 🎨 Simple, clean, and user-friendly interface
